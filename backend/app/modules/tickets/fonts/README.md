# Ticket PDF fonts

Noto Sans Regular and Bold, unmodified, from:

- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- https://github.com/notofonts/noto-fonts/blob/main/LICENSE

Bundled under the SIL Open Font License in `LICENSE` so ticket PDFs render
Kazakh/Russian names on local and Docker deployments without system fonts.
